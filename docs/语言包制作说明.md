# 语言包制作说明

IPv4OctetSort v0.4 起，界面文字全部外置在 `languages/*.lng` 文件中。
**新增一种语言 = 把一个 `.lng` 文件放进 `languages/` 目录重新编译**，
不需要改动任何源代码。

## 快速开始

1. 复制 `languages/en-US.lng`，改名为 `<locale>.lng`
   （locale 用 BCP-47 标签，如 `de-DE`、`es-ES`、`pt-BR`）
2. 把文件内的 `locale` 改成新标签，`name` 改成该语言的自称
   （如 `Deutsch`、`Español`——下拉菜单按此显示，**永远用该语言自身书写，不随界面语言变化**）
3. 逐条翻译其余键（键名保持不变，见下）
4. 运行 `build\build.bat` 重新编译；跑 `build\build_tests.bat` 自检

编译时 `tools/lng2cpp.cpp` 会自动扫描 `languages/*.lng` 并把它们全部打进 exe，
语言下拉菜单自动多出一项。

## 文件格式

- UTF-8 编码（带不带 BOM 均可），换行随意
- `#` 或 `;` 开头的行是注释；空行忽略
- 每行一条 `键 = 值`；`=` 前后空白会被忽略
- **值首尾的空格会被去除**——条目之间的分隔符（空格、间隔号「·」、顿号）写进值内部
- 值内转义：`\t`（制表符，用于菜单快捷键）、`\n`、`\r`、`\\`、
  `\xNN`（两位十六进制，如 `\x20` = 空格，用于需要保留尾随空格的场景）

```
# 示例：德语语言包的开头
locale = de-DE
name = Deutsch

WindowTitle = IPv4OctetSort — IPv4-Adresssortierung
MenuClear = Eingabe &löschen\tCtrl+D
```

规则约束（违反会被测试拦下）：

- `locale` 必须与文件名一致（不含扩展名）
- 键名只能是字母、数字、下划线，且以字母开头
- 键集合必须与 `en-US.lng` 完全一致：不缺键、不多键（`locale`、`name` 除外）
- 每个值非空
- 带 `%d` / `%s` 的值必须与英语参考的格式符个数、类型一致
  （`%d` 填整数、`%s` 填字符串，`%%` 输出百分号）

## 键清单

全部键定义在 `src/ui/text_keys.h`（`UI_TEXT_LIST` 宏），与程序里的
`StrId` 枚举一一对应。带格式符的键在代码里用 `Tf()` 按顺序填充，
翻译时**只能改文字、不能增删格式符，也不能交换 %d / %s 的类型**。

写作约定：

- 用词遵循软件行业通用术语（排序用 sort/order、缺位用 gap、掩码用 prefix/mask、
  八位组用 octet……）
- 菜单助记符 `&X` 跟在单词中对应字母后（如 `&File`）；`\t` 后写快捷键
- 工具栏按钮、复选框文字宜短：窗口宽 880 px，工具栏按各语言实测文字宽度排布，
  过长的文字会被省略号截断。参考现有语言包的长度（俄语等宽文字语言用了
  「Возрастание / Без дубликатов」这类精简写法）

## 运行时行为

- 界面查找顺序：**当前语言 → 英语（en-US）→ 键名**。语言包漏译某键时
  自动回退英语，不会留白
- 语言选择写入注册表 `HKCU\Software\IPv4OctetSort\Language`（BCP-47 标签），
  下次启动沿用；无记录时跟随系统界面语言，无匹配回退英语
- 语言文件损坏时该语言仍可列出（键全部回退英语），程序照常启动
